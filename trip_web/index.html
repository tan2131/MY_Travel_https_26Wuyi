核心提醒

根据你的攻略整理成旅行时能快速看的卡片。

行程时间线

可以按日期筛选；每条行程可下载日历提醒，也可以跳到地点导航。

地点攻略与地图导航

网页无法像小程序那样直接调微信地图，但可以打开腾讯地图/高德地图链接，或复制地点名。

出发前检查清单

勾选状态会保存在当前浏览器里。换手机或清缓存后需要重新勾选。

导入文档攻略

可以把 Word / Excel / PDF 存在当前浏览器本地数据库里，方便旅行时从网页入口打开或下载；不会上传到服务器。

把攻略文件导入到本页面

提示：iPhone/微信内置浏览器对下载和打开本地文件有限制，建议同时把攻略文件发到微信收藏或文件传输助手。

返程方案

返程高峰不要卡点，最终以你买到的车票为准。

发布与二维码

上传到静态网站平台后，把生成的网址粘贴到这里，可以临时生成二维码给同行扫码。

网址转二维码

先把本文件夹发布成网址，再把网址粘贴进下面输入框。二维码图片由公开二维码接口生成；如果打不开，也可以把网址发给我，我帮你生成二维码图片。

如果只是自己和同行使用，最推荐 Netlify Drop 或 Cloudflare Pages 直接拖拽上传。
