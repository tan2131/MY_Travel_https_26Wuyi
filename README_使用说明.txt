五一旅行助手网页版 - 使用说明

这个文件夹是纯静态网页，不需要微信开发者工具，也不需要后端服务器。

文件说明：
- index.html：主网页，双击可在浏览器打开，也可以上传到网站平台。
- README_发布与二维码.txt：上传网站和生成二维码的方法。

本网页已包含：
1. 5月1日—5月3日行程时间线
2. 茂名 / 玉林地点攻略
3. 腾讯地图 / 高德地图跳转
4. 日历提醒 .ics 下载
5. 出发清单勾选保存
6. 本机浏览器导入 Word / Excel / PDF 攻略文档
7. 发布后网址转二维码入口

注意：
- 网页不能像手机闹钟那样在后台强制响铃，真正提醒建议下载 .ics 日历文件并导入手机日历。
- 文档导入功能是保存在当前浏览器的 IndexedDB 本地数据库，不会上传到服务器。
- 如果换手机、换浏览器或清缓存，清单和导入文档可能会消失。
- 地图链接依赖手机是否安装对应地图 App 或浏览器支持。
